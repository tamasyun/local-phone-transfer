# スマホファイル転送ランチャー

Windows 11 共用PCと iPhone / Android の間で、**インターネットを使わずに**ファイルを送受信するためのランチャーです。

スマホ側にはアプリをインストールしません。Safari / ChromeなどのWebブラウザだけで利用できます。

## できること

- iPhone → PC
- Android → PC
- PC → iPhone
- PC → Android
- PDF / Word / Excel / PowerPoint / ZIP / 画像 / 動画など、任意ファイルを転送
- インターネット接続不要
- 外部クラウド不要
- Apple Account / Googleアカウント / Microsoftアカウント不要
- スマホ側アプリ不要
- QRコードをローカル生成
- PC起動ごとに新しい転送URLを生成
- 管理画面はPC自身（localhost）からのみ利用可能
- 一定時間後に自動終了

---

# 推奨する接続構成

最も安定するのは、**転送専用のWi-Fiルーターを1台置き、WAN（インターネット）には接続しない**構成です。

```text
                 インターネット
                      │
                 あってもなくてもよい
                      │ Wi-Fi（任意）
                      ▼
               ┌────────────┐
               │ Windows 11 │
               │   共用PC    │
               └─────┬──────┘
                     │ Ethernet
                     │
               ┌─────▼──────┐
               │ 転送専用     │
               │ Wi-Fiルーター │
               │ WAN未接続    │
               └─────┬──────┘
                    Wi-Fi
                ┌────┴────┐
             iPhone     Android
```

PCのWi-Fiは普段のインターネット接続に使ったまま、転送専用ルーターとはEthernetで接続できます。

## 転送専用ルーターの推奨設定

例：

```text
SSID:          PC-FileTransfer
暗号化:        WPA2-Personal または WPA3-Personal
パスワード:    任意の十分に長いパスワード
LAN IP:        192.168.50.1
DHCP:          ON
DHCP範囲:      192.168.50.100 ～ 192.168.50.200
WAN:           未接続
```

> 「APモード」でDHCPが停止する機種があります。その場合はスマホとPCにIPが配られません。単独で使う場合は、ルーターモード等で **DHCPサーバーが有効**になる設定を使ってください。WANケーブルは挿さなくて構いません。

# 最初に1回だけ行う設定

## 1. フォルダーを共用PCへ配置

このフォルダーを、例えばデスクトップに置きます。

```text
デスクトップ
└─ スマホファイル転送
   ├─ スマホファイル転送.exe
   ├─ transfer-config.json
   ├─ 初期セットアップ.cmd
   └─ ...
```

配置後はなるべく場所を変更しないでください。WindowsファイアウォールはEXEの場所も条件として使用します。

## 2. 転送専用ルーターをPCへ接続

- ルーターのLANポート → 共用PCのEthernetポート
- WANポート → 何も接続しない
- スマホ → ルーターのWi-Fiへ接続

## 3. `初期セットアップ.cmd` を実行

管理者権限の確認が表示されます。

この処理では、Windowsファイアウォールに次の受信規則を追加します。

- TCP 8765
- 対象：このランチャーのみ
- 接続元：LocalSubnetのみ

ファイアウォール全体を無効化することはありません。

## 4. `transfer-config.json` を設定

最低限、以下をルーターと合わせてください。

```json
"wifiSsid": "PC-FileTransfer",
"wifiPassword": "ここを実際のWi-Fiパスワードにする"
```

推奨ネットワークを192.168.50.xにした場合は次をそのまま利用できます。

```json
"preferredIpPrefix": "192.168.50."
```

# 普段の使い方

## PC側

`スマホファイル転送.exe` をダブルクリックします。

既定のWebブラウザで操作画面が自動的に開きます。

画面は次の順番です。

1. スマホを転送用Wi-Fiへ接続するQRコード
2. スマホで転送ページを開くQRコード
3. ファイル送受信画面

## スマホ側

### STEP 1

PC画面の最初のQRコードをスマホのカメラで読み込み、転送用Wi-Fiへ接続します。

iPhone / Androidから

> インターネットに接続されていません

などと表示されても正常です。**そのWi-Fiへの接続を維持してください。**

### STEP 2

PC画面の転送ページQRコードを読み取ります。

Safari / Chromeで次のような画面が開きます。

```text
スマホ ⇄ 共用PC

[ スマホ → PC ]
ファイルを選んで送信

[ PC → スマホ ]
共有中のファイル一覧
```

### STEP 3：スマホ → PC

「ファイルを選んで送信」を押します。

iPhoneでは「ファイル」「写真」などから送信対象を選択できます。

受信したファイルはランチャーと同じ場所の

```text
受信ファイル
```

へ保存されます。

### STEP 3：PC → スマホ

PC画面で

> PCからスマホへ共有するファイルを選ぶ

を押してファイルを選択します。

スマホ画面の「PC → スマホ」欄に表示されるので、「受け取る」を押します。

---

# 終了

PC画面の

> 転送を終了する

を押します。

終了すると、その起動時に生成されたスマホ用URLは無効になります。

標準設定では、終了時に「送信ファイル」フォルダーの共有ファイルを削除します。

さらに、終了操作を忘れた場合でも **60分後に自動終了**します。

# 設定項目

`transfer-config.json`

| 項目 | 意味 |
|---|---|
| `deviceName` | スマホ画面に表示するPC名 |
| `port` | 転送サーバーのTCPポート |
| `receiveDir` | スマホ→PCの保存先 |
| `sendDir` | PC→スマホの共有用保存先 |
| `maxUploadMB` | 1ファイルあたりの最大サイズ(MB) |
| `preferredInterfaceContains` | 優先したいネットワークアダプター名の一部 |
| `preferredIpPrefix` | 優先するIPv4アドレスの先頭部分 |
| `wifiSsid` | PC画面に表示する転送用Wi-Fi名 |
| `wifiPassword` | PC画面・Wi-Fi QRに使うパスワード |
| `clearSendOnExit` | 終了時にPC→スマホ共有ファイルを削除するか |
| `autoStopMinutes` | 自動終了までの分数。0で無効 |

# セキュリティ上の設計

- 転送ページURLは起動ごとにランダム生成
- 管理ページURLも起動ごとに別のランダム値を生成
- 管理ページは `127.0.0.1` / `::1` からのアクセスだけ許可
- ファイル名のパストラバーサル対策
- アップロードサイズ制限
- アップロード途中のファイルは一時ファイルとして保存し、完了後に確定
- Windowsファイアウォール規則は `LocalSubnet` に限定
- インターネット上のサーバーへデータを送信しない

## 注意

転送ページ自体はローカルHTTPです。公共Wi-Fiなど不特定多数が参加するネットワークではなく、WPA2/WPA3で保護された**転送専用Wi-Fi**で使ってください。

# Windows SmartScreenについて

このEXEには商用コード署名証明書によるデジタル署名を付けていません。

そのため環境によってはWindows SmartScreenが警告する場合があります。運用する共用PCでは、管理者が内容を確認したうえで配置してください。

# 対応OS

- Windows 11 x64: `スマホファイル転送.exe`
- Windows 11 ARM64: `スマホファイル転送_ARM64.exe`

一般的なIntel / AMD搭載Windows PCではx64版を使います。
