# Offline File Transfer

Windows PC とスマートフォンの間で、同じインターネット接続やクラウドサービスを使わずにファイルを転送するためのポータブルアプリです。

## 使い方

1. GitHub Releases から最新版の ZIP をダウンロードします。
2. ZIP を展開します。
3. 展開したフォルダの `Start.cmd` を実行します。
4. 初回のみ、Windows Firewall の設定のため管理者権限を求められることがあります。
5. PC 画面に表示される案内に従って、スマートフォンから転送用 Wi-Fi に接続します。
6. QR コードまたは表示された URL からスマートフォン側の転送画面を開きます。

## ファイル転送

- **スマートフォン → PC**: スマートフォン側でファイルを選んで送信します。
- **PC → スマートフォン**: PC 側で共有するファイルを選び、スマートフォン側の一覧から受け取ります。
- スマートフォン側で OS の共有機能が利用できる場合、受け取り時に標準の共有シートを表示します。
- 共有機能が利用できないブラウザでは、ファイルをダウンロードします。

## 終了

PC 側の操作画面から「ファイル転送を終了」を押してください。転送用 Wi-Fi も停止します。

## 言語

PC 側の操作画面にある `Language / 言語` から、日本語または English を選択できます。選択内容は次回起動時にも保持されます。

## テストモード

開発・確認用に `app\Launch-Test.cmd` があります。テストモードでは Wi-Fi Direct や Firewall の変更を行わず、PC 内の `127.0.0.1` のみで動作します。

## 対応環境

- Windows 11
- x64 / ARM64
- Wi-Fi Direct Legacy AP に対応した Wi-Fi アダプター

## 注意事項

- 転送中は起動したコンソール画面を閉じないでください。
- 自動アップデートにはインターネット接続が必要です。オフラインの場合は現在のバージョンで起動します。
- 配布バイナリはコード署名されていません。Windows のセキュリティ機能によって警告が表示される場合があります。
