# Offline File Transfer

Windows 11 PC と iPhone / Android の間で、クラウドやインターネットを転送経路として使わずにファイルを送受信できるローカルファイル転送ツールです。

PC が転送専用の Wi-Fi Direct ネットワークを作成し、スマートフォン側は Safari / Chrome などのブラウザだけで利用できます。スマートフォンへのアプリのインストールは不要です。

## 使い始める

1. GitHub Releases から最新の **`OfflineFileTransfer-<version>.zip`** をダウンロードします。
2. ZIP を展開します。
3. 展開したフォルダ内の **`Start.cmd`** を開きます。
4. 初回のみ、Windows Firewall の設定のため管理者権限を求められたら許可します。

インストールは不要です。展開したフォルダがそのままアプリ本体なので、利用中はフォルダを残してください。

## 使い方

1. **`Start.cmd`** を開きます。
2. PC のブラウザに表示された「接続の準備」に従います。
3. スマートフォンを表示された転送用 Wi-Fi に接続します。
4. QR コードを読み取り、スマートフォンのブラウザで転送ページを開きます。
5. PC → スマホ、スマホ → PC のどちらの方向でもファイルを転送できます。

## 終了するとき

転送が終わったら、PC 画面下部の **「ファイル転送を終了」** を押してください。

ブラウザのウィンドウを閉じるだけではなく、終了ボタンから終了してください。

## 削除するとき

アプリを終了したあと、展開した **`OfflineFileTransfer`** フォルダを削除してください。

## 主な機能

- Windows 11 PC と iPhone / Android 間の双方向ファイル転送
- スマートフォン側アプリ不要
- インターネットをファイル転送経路として使用しない
- PC が転送専用 Wi-Fi を作成
- 起動ごとに新しい Wi-Fi パスワードを生成
- QR コードからスマートフォンの転送ページを開ける
- 複数ファイルの送受信
- 1ファイルあたり最大 2 GB
- 長時間放置時の自動終了
- 自動アップデート
- 日本語 / English 対応

## セキュリティ

ファイル転送は、起動時に作成される専用 Wi-Fi ネットワーク内に限定されます。

また、セッションごとに異なる転送 URL を使用し、PC の管理画面はPC自身からのみアクセスできるよう制限しています。Windows Firewall も転送用ネットワークからの通信だけを許可します。

## 対応環境

- Windows 11 x64
- Windows 11 ARM64
- iPhone / iPad の Safari
- Android の Chrome などの一般的なブラウザ

## 旧版を使用している場合

ProgramData にインストールする旧版を使用している場合は、最新の Release をダウンロードして展開し、以後は `Start.cmd` から起動してください。
